# PathPilot — GBFS Lab

An interactive web explainer for Greedy Best-First Search, built with Streamlit and Plotly.

## Run locally

1. Install Python 3.10 or later.
2. Open a terminal in this folder.
3. (Optional) Create and activate a virtual environment.
4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Start the web app:

   ```bash
   streamlit run app.py
   ```

6. Open the local URL printed by Streamlit, usually http://localhost:8501.

## Features

- Interactive maze presets
- Manhattan and Euclidean heuristic selection
- Step-by-step GBFS execution
- Run-to-goal and reset controls
- Frontier ranking and heuristic values
- Explored-node and path-length metrics
- Explanation panels and experiment notes

## Notes

This is an educational visualization, not a medical, safety, or production path-planning tool.
